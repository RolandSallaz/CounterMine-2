# AK74 equip и idle

Исходник: `Assets/Anims/AK74_Equip.blend`. Эквип — кадры 1–52, 60 FPS, длительность 0,85 с. Пользовательская анимация сохранена.

В исходник добавлены Actions `AK74_Idle_Character` (Root) и `AK74_Idle_Weapon` (AK74): одна поза на кадре 1, скопированная с кадра 52 эквипа. Для просмотра idle выберите обе соответствующие Actions. По умолчанию в исходнике остаётся выбран эквип.

Четыре FBX содержат экспорт персонажа и оружия отдельно для equip/idle. Экспорт запекает Blender IK и Child Of с шагом один кадр, Simplify = 0. В Unity у всех четырёх импортов Animation Compression = Off. Игрок использует извлечённые `.anim`, у которых `m_Compressed = 0`. Idle содержит по одному ключу на канал на времени 0 и не зациклен.

Настройки единиц обязаны совпадать с основными моделями: Apply Unit = true, Apply Scalings = FBX Units Scale (`FBX_SCALE_UNITS`). Иначе клип записывает масштаб Root=100 вместо 1 и ломает скиннинг при воспроизведении на основном персонаже. После исправления проверены мировые координаты скинированных вершин персонажа и оружия против Blender в пяти точках анимации.

Игровые модели остаются `Assets/models/character.fbx` и `Assets/models/AK-74.fbx`; экспортные FBX не заменяют их в префабе. Координаты анимации оружия приведены к скелету основного AK-74. `WeaponAnimationSpace` под WeaponRecoilPivot компенсирует высоту камеры из Blender, не меняя её положение.

На Player настроен WeaponIdleSynchronizer: сначала equip, затем статический idle. Старые клипы PlayerAnimancerController отвязаны, чтобы второй граф не перезаписывал тот же скелет.

Правило действий: WeaponHandIK работает только в idle. Пока проигрывается действие или нет готовой idle-пары, стрельба блокируется в WeaponRecoilController и NetworkWeapon.FireLocalShot; прицеливание также недоступно. Для будущих перезарядок и других действий вызывайте `PlayAction(characterClip, weaponClip)`, чтобы применялись те же ограничения. `PlayEquip()` повторяет эквип, `RestartIdle()` сразу возвращает idle.

Проверка в Unity: реальные графы Animancer на пяти точках эквипа, автоматический переход в idle, нулевой скачок кистей, корректное включение IK и отклонение FireLocalShot во время действия. Проверена компрессия и соответствие путей костей. Сетевой матч отдельно не запускался; синхронизация произвольных PlayAction между клиентами этим изменением не добавляется.
