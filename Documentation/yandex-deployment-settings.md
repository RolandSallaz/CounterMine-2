# Проверка настроек Яндекс Игр — 23 сентября 2026

По просьбе пользователя WebGL-билд не запускался. Проверены файлы проекта и приведённая ошибка браузера; доступ к консоли Яндекс Игр не использовался.

## Результат

PhotonServerSettings уже использует WebSocketSecure (Protocol: 5), UseNameServer: true, регион eu, автоматический порт (0), без собственного Server/ProxyServer. LobbyManager вызывает ConnectUsingSettings. Это нормальная конфигурация Photon Cloud для WebGL; заменять её на фиксированный Master Server не требуется.

CSP пропускает ns.photonengine.io, но блокирует выданный Photon адрес gcams1128.exitgames.com. Разрешение *.ns.photonengine.io не распространяется на *.exitgames.com или другие поддомены photonengine.io. Name Server, Master Server и Game Server — разные этапы подключения.

## Необходимая настройка в консоли Яндекс Игр

Уточнение по проверке пользователя: поле хоста отклоняет маски со звёздочкой. Не вводить следующие маски в поле; запросить их разрешение через поддержку:

- *.exitgames.com
- *.photonengine.io

Сохранить существующие записи exitgames.com и photonengine.io и проверить, одобрены ли они и применены ли к черновику: их наличие в форме само по себе не доказывает наличие в действующей CSP. В приведённой ошибке разрешения exitgames.com нет. Для конкретного заблокированного сервера можно подать хост gcams1128.exitgames.com без wss://, порта и /Master/. Один такой хост не покрывает динамически назначаемые Master/Game Servers. Существующее разрешение ns.photonengine.io сохранить.

Текст обоснования: «Photon Cloud используется для сетевого режима игры: поиск комнат и синхронизация игроков через защищённый WebSocket (WSS). Name Server перенаправляет клиентов на динамические Master Server и Game Server в доменах exitgames.com и photonengine.io. Требуется доступ к их поддоменам».

Источники: [порядок настройки CSP Яндекс Игр](https://yandex.ru/dev/games/doc/ru/console/add-new-game), [описание доменов и динамических адресов Photon](https://doc.photonengine.com/pun/current/connection-and-authentication/discord-activities).

После одобрения правил повторить запуск черновика и проверить как вход на Master Server, так и создание/вход в комнату. Локальный index.html не может ослабить ограничения CSP, которые применяет платформа. Переписывание адреса exitgames.com на ns.photonengine.io не является корректной заменой сервера.

## Остальные проверенные настройки

- Основной проект и оба Web-профиля используют PROJECT:YandexGames.
- Шаблон подключает /sdk.js и вызывает YaGames.init().
- Потоки WebGL выключены.
- В сценах сборки включена Assets/Scenes/SampleScene.unity.
- Есть вывод состояния подключения и кнопка повторного подключения в DeploymentScreen.
- Сжатие и decompression fallback не являются причиной приведённого CSP-отказа: код игры уже выполняется и пытается открыть WebSocket. Серверные заголовки загруженного архива в рамках этой проверки не проверялись.

Конфигурация Photon и настройки сборки не изменялись: для устранения указанной ошибки нужно разрешение внешних хостов на стороне площадки. Успешное соединение из опубликованного черновика пока не подтверждено.
