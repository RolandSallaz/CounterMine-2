# Звуки и киллфид

Рабочий профиль: `Assets/Resources/Audio/Weapons/ak74.asset`.
Он уже назначен в `WeaponIdleSynchronizer → Weapons → ak74 → Audio Profile`
в префабах `Player` и `Bot`. Доступны три варианта выстрела, equip, reload,
dry fire, громкость, дальность и разброс pitch.

Для новой пушки: Create → CounterMine → Weapon Audio, заполнить клипы и назначить
профиль в её записи Weapons. Для отображения названия оружия на других клиентах
сохранить профиль в `Assets/Resources/Audio/Weapons/<weaponId>.asset` и заполнить
Display Name. ID должен совпадать с ID оружия. Все клиенты должны использовать
одну версию каталога. Для AK-74 это `ak74`.

Выстрел использует существующее подтверждение Photon; владелец слышит звук сразу,
остальные — при подтверждении мастером. Номер выстрела определяет вариант и pitch.
Повторное подтверждение не воспроизводит звук повторно. Мастер сохраняет ID оружия
в летящей пуле и передаёт его вместе со смертельным уроном в snapshot здоровья.
Старые snapshots здоровья по-прежнему читаются, но не содержат названия оружия.

`PlayerAudio` подключается автоматически из PlayerOwnershipSetup. Шаги зависят от
пройденного расстояния и наличия земли; нет шагов при подкате, смерти и телепорте.
Одинаковые бетонные шаги пока используются на всех поверхностях. Equip/reload
следуют ActionId и StartedAt, включая удалённых игроков. Это целые звуковые клипы,
а не покадровые события магазина и затвора: для точного совпадения с другой
анимацией следует подготовить соответствующий ей клип. Общий пул ограничен
32 AudioSource; источники переиспользуются. UI и собственное оружие звучат в 2D,
оружие других игроков — в 3D без эффекта Доплера.

Исходные архивы остаются вне Assets и не входят в сборку. В Assets добавлены
11 моно WAV; Unity импортирует их с компрессией Vorbis.
Список источников и обработки — selected-clips.json; лицензии входят в сборку
через `Assets/StreamingAssets/AudioCredits.txt`. Текущие используемые записи CC0.
Запись AK-47 временно используется для AK-74, это не аутентичная запись AK-74.
Скачанный сборник Footsteps on Different Surfaces пока не включён: шаги взяты
из выбранного Kenney Impact Sounds.

Киллфид использует динамический шрифт, размер 20, pixel-perfect Canvas и более
контрастную подложку. Убийства ботами и игроками с одинаковыми никами не считаются
суицидом. Строка показывает убийцу, ассистента (если есть), оружие и жертву.

Проверки: C# игры и Editor компилируются; Unity импортировала 11 непустых моно
клипов, проверены ссылки профилей, строки с ботом/ассистентом/одинаковыми никами.
Результат: `Validation/unity-validation.txt`, снимок: `Validation/killfeed-preview.png`.
Живое прослушивание и сетевой тест двумя клиентами в эту проверку не входят.

Звуки попаданий отключены по запросу; их клипы удалены из Assets. Искры и следы пуль сохранены.

Фоновая музыка: `Assets/Resources/Audio/Music/action_loop.wav` — "Action Music
Loop" by AppPro, CC0 via OpenGameArt
(https://opengameart.org/content/action-music-loop). Стерео WAV 34 c,
бесшовный цикл: `GameAudio.PlayMusic` на выделенном 2D-канале с `loop`,
автостарт после загрузки сцены, громкость 0.35.
