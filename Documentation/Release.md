# Подготовка сборки для Яндекс Игр

## Старт игры

При загрузке открывается экран подготовки с магазином и кнопкой «В бой». Подключение к комнате и загрузка профиля идут в фоне. Кнопка входа в бой доступна после их завершения; до нажатия сетевой персонаж не создаётся. Выбор магазина применяется к первой жизни. После смерти используется прежний экран магазина и возрождения.

## HTML

В `Project Settings > Player > Web > Resolution and Presentation > WebGL Template` выбран `YandexGames` (`PROJECT:YandexGames`). Исходный шаблон: `Assets/WebGLTemplates/YandexGames/index.html`. Он подключает `/sdk.js`, инициализирует SDK и загружает Unity. В корне готовой WebGL-сборки должен находиться созданный из него `index.html`.

Автоматическая сборка `WebGLBuildGhPages.Build` также использует этот шаблон. Пересобери WebGL: смена настройки не обновляет уже выпущенные папки сборок. Загружай в Яндекс Игры весь результат сборки, включая `Build`, `style.css` и папку `Images`.

## Языки

Поддерживаются русский и английский. Язык берётся из `ysdk.environment.i18n.lang`; остальные языки используют английский. Это [поле языка интерфейса Яндекс Игр](https://yandex.ru/dev/games/doc/ru/sdk/sdk-environment). Тексты хранятся в `Assets/Resources/GameTranslations.json`. SDK выбирает язык, переводы подготовлены в проекте; автоматический машинный перевод не используется.

У установленного Plugin Your Games нет дополнительного модуля Language, поэтому используется небольшой `YandexLanguage`/`CounterMineLanguage.jslib`, читающий уже инициализированный SDK шаблона. Статические подписи обновляются при смене языка, динамические — при следующем обновлении HUD. Имена игроков и идентификаторы оружия не переводятся.

В редакторе меняй `Simulation > Language` у `Assets/plugins/PluginYourGames/Resources/SettingsYG2.asset`: `ru`, `en`, затем неизвестный язык для проверки английского резерва. Проверь стартовый экран, магазин, боевой HUD, захват точек, результаты, ленту убийств и возрождение. В обычной локальной WebGL-сборке без SDK используется английский.

## Проверка перед публикацией

1. Выполни `Tools > CounterMine > Validate Release UI`.
2. В Play Mode проверь: экран подготовки → магазин → выбор → «В бой» → смерть → магазин → возрождение. До входа в бой не должно быть тела игрока, смерти или награды за убийство.
3. Проверь обе локали и длинные подписи на небольшом окне.
4. Собери WebGL и открой черновик Яндекс Игр: проверь язык SDK, загрузку HTML, покупки/сохранения, первое появление и повторный вход.
5. Проверь матч в двух клиентах. Редакторские проверки не заменяют сетевой матч и проверку в браузере на площадке.

Добавление оружия описано в [ADDING_WEAPONS.md](NewWeapons/ADDING_WEAPONS.md).
