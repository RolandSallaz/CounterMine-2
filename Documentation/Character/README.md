# Единый персонаж

- `Assets/models/character.blend` — основной редактируемый исходник рядом с FBX, T-поза, без оружия и клипов. Внутри есть камера `PlayerCamera` для создания анимаций от первого лица. Unity также видит исходник как импортируемый ассет, но Player использует только FBX.
- `Assets/models/character.fbx` — единственная игровая модель персонажа. На неё ссылается `Assets/Resources/Player.prefab`.
- `Assets/models/CharacterMaterials/Team1/Materials` — сине-серая палитра.
- `Assets/models/CharacterMaterials/Team2/Materials` — кирпично-красная палитра.

В Blender выберите скелет `Root` → Object Properties → Custom Properties → `Team`: 1 или 2. Эта настройка меняет только цвета общей модели. Для просмотра используйте Material Preview либо Solid → Color Type: Material. Если после изменения не обновился Solid viewport, переключите кадр. IK-контроллеры сохранены для ручной анимации; готовых Actions нет.

В Unity компонент `CharacterTeamColors` на Player использует уже существующее свойство Photon `team` владельца игрока. Обе команды используют одну геометрию и общие материалы; экземпляры материалов для каждого игрока не создаются. В меню компонента есть Preview Team 1 / Preview Team 2. Палитры и переключение в обе стороны проверены в редакторе; сетевой матч отдельно не тестировался.

После редактирования исходника экспортируйте FBX поверх `Assets/models/character.fbx`, сохраняя существующий `.meta`. Экспорт: объекты Mesh и Armature, Forward -Z, Up Y, Apply Unit, Add Leaf Bones выключено. Для нейтральной модели Bake Animation выключено. Сохраняйте имена `Root`, `arms`, `characterTps` и костей, чтобы не потерять ссылки префаба. Перед экспортом установите Team=1. После добавления своих анимаций включите нужные настройки экспорта и импорта клипов.

Исходник содержит один скелет и несколько скинированных частей (тело, руки, снаряжение); это один персонаж, а не варианты геометрии для команд. Детали сохраняют собственные материалы.

Старые варианты и прежний Player.prefab сохранены вне Assets в `Backups/CharacterConsolidation_20260916_114934`. Отдельный AK-74 и прежние .anim клипы не удалены. Текущий Player использует пользовательский эквип и однокадровый idle из `Assets/Anims/Ak74/Exported`; старые конкурирующие клипы контроллера отвязаны.

Превью: `Team1.png` и `Team2.png`. Итоговая проверка Unity: `fbx_unity_validation.txt`.

## Камера для анимаций

В Blender нажмите **Numpad 0**: активная камера `PlayerCamera` соответствует нейтральной камере Player.prefab. Положение Unity `(0, 1.65, 0.12)` преобразовано в Blender `(0, -0.12, 1.65)` с учётом осей. Вертикальный FOV — 75°, near/far — 0.01/1000 м. Предпросмотр настроен на 1920×1080 (16:9); для точного совпадения кадра используйте такой же aspect в Unity Game View. Камера стоит отдельно от костей, как и в префабе. Приседание, наклон, отдача и прицеливание в игре изменяют базовый вид.

При экспорте FBX оставляйте типы объектов Mesh и Armature: камера нужна для работы в Blender, игровая камера уже находится на Player. Основной FBX при добавлении авторской камеры не изменялся.
