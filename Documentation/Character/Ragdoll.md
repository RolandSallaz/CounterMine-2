# Ragdoll игрока

В Play Mode клавиша **F8** переключает ragdoll своего игрока. Также доступны команды Debug в контекстном меню компонента PlayerRagdollController.

При включении физика управляет скелетом, управление, IK и анимация приостанавливаются, оружие остаётся прикреплённым к правой кисти, камера следует за головой. Повторное F8 возвращает игрока в исходную точку и idle. Это тестовый сброс, а не анимация вставания.

При смерти ragdoll включается автоматически; F8 не воскрешает погибшего игрока. Отладочные команды доступны только в Editor и Development Build. Подсказка отключается полем Show Debug Hint, команды — Debug Controls.

В комнате переключение отправляется всем участникам через Photon RPC с проверкой владельца. Каждая машина симулирует тело самостоятельно: точная поза костей по сети не передаётся.

Настройка: 14 физических тел, 13 суставов ConfigurableJoint, суммарная масса 72,825 кг. Генерация использует RootMotion Ragdoll Manager. Во время обычной анимации тела кинематические, их коллайдеры отключены.
