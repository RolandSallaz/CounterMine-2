# Устойчивость регдолла

Для физики тела используется ContinuousSpeculative вместо ContinuousDynamic:
первый режим учитывает вращение конечностей при прогнозировании контакта.
Это устраняет один из возможных источников прохождения рук/ног через тонкий пол;
причина конкретного случая на игровой карте ещё требует воспроизведения.
Описание ограничений режимов: https://docs.unity3d.com/Manual/sweep-based-ccd.html

Только у тел регдолла повышены solverIterations до 12 и solverVelocityIterations
до 4; maxAngularVelocity ограничена 20 рад/с, maxDepenetrationVelocity — 3 м/с.
Глобальные настройки физики, слои и геометрия карты не менялись.

Tools → CounterMine → Validate Ragdoll Ground проверяет Player и Bot с тремя
импульсами на 4-сантиметровом полу в отдельной физической сцене, по 8 секунд.
Отчёт после выполнения: ragdoll_ground_validation.txt либо ragdoll_ground_error.txt.
Проверка не воспроизводит сетевую задержку или все поверхности реальной карты.
