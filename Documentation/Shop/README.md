# Магазин на экране смерти

Кнопка «МАГАЗИН / СНАРЯЖЕНИЕ» открывает три вкладки: основное оружие, пистолеты, навыки / киллстрики. Покупки оплачиваются накопленными деньгами и сохраняются навсегда вместе с профилем. Уже купленные предметы выбираются бесплатно; выбранное снаряжение применяется при следующем возрождении. Пока магазин открыт, клавиши быстрого возрождения отключены.

АК-74, HK UCP, радар и Milkor выданы и экипированы по умолчанию бесплатно. Существующие профили получают этот набор при однократной миграции, без списания денег. Последующее снятие навыков сохраняется.

Каталожные цены задаются в `Assets/Resources/ShopCatalog.asset`; для уже выданного стартового набора покупка не требуется:

| Предмет | Цена | Клавиша |
| --- | ---: | --- |
| АК-74 | бесплатно | 1 |
| HK416 | 600 | 1 |
| L115A3 | 1200 | 1 |
| HK UCP | 150 | 2 |
| Радар | 250 | 3; награда за 5 убийств |
| Milkor MGL Mk 1S | 500 | 4; награда за 10 убийств |

Покупка навыка открывает его использование: заряд по-прежнему нужно заработать убийствами. Навык можно убрать из снаряжения без потери покупки.

Сохранение использует существующий YandexCloudSave: облако в Yandex WebGL, PlayerPrefs в редакторе и остальных сборках. Старые профили проходят миграцию. Проверки не меняют настоящий кошелёк игрока.

`Tools > CounterMine > Install and Validate Death Shop` создаёт иконки из моделей, проверяет покупки, сохранение и все вкладки. Результаты в `validation.txt`, превью в `Primary.png`, `Pistol.png`, `Skill.png`. Это редакторские проверки; сетевой матч и WebGL-сборка отдельно не запускались.
