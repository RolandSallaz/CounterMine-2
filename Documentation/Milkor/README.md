# Milkor MGL Mk 1S

Навык в слоте **4**. Каждые **10 убийств противников** дают один заряд; убийства ботов тоже учитываются. Прогресс и неиспользованные заряды сохраняются после смерти, но сбрасываются в новом раунде.

- **4** — активировать навык или снова достать оставшийся гранатомёт.
- **ЛКМ** — одиночный выстрел, интервал 0,55 секунды.
- **ПКМ** — прицеливание.
- **1 / 2** — вернуться к обычному оружию; оставшиеся гранаты сохраняются до смерти.
- В барабане **6 гранат**, перезарядки и пополнения нет. После шестого выстрела автоматически возвращается предыдущее оружие.

Модель использует URP-материалы: оливковое покрытие, тёмный металл, чёрный полимер, латунные детали и стекло оптики. Доставание длится 0,72 секунды и рассчитывается процедурно; руки следуют за оружием через IK. Барабан поворачивается после каждого выстрела.

Гранаты летят по баллистической дуге со скоростью 32 м/с и взрываются при попадании, с аварийным таймером 6 секунд. Радиус урона — 6 м; в пределах 2 м урон 110, далее снижается до 15. Укрытия и безопасные зоны блокируют урон. Союзники защищены, собственный взрыв опасен для стрелка.

Мастер матча подтверждает получение навыка, лимит патронов и запуск гранат. Состояние награды хранится в свойствах комнаты для смены мастера.

Повторная установка ассетов: `Tools > CounterMine > Install Milkor MGL`.
Проверка: `Tools > CounterMine > Validate Milkor MGL`.
Результаты редакторских проверок — `validation.txt`, превью — `model.png` и `first-person.png`. Полный сетевой матч и WebGL-сборка этими проверками не заменяются.
