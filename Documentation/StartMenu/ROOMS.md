# Комнаты мультиплеера

Кнопка «Мультиплеер» открывает список комнат Photon для текущей версии игры. Поиск фильтрует названия без учёта регистра. Список показывает заполненность; закрытые и заполненные комнаты недоступны для входа. «Обновить» переподключается к lobby и получает свежий список.

«Создать» открывает публичную комнату на 16 игроков. Можно указать название до 32 символов; пустое поле даёт случайное имя. «Быстрый вход» ищет открытую комнату через Photon и создаёт новую, если подходящих матчей нет. Экран высадки появляется только после успешного входа в комнату. «Назад» закрывает список и отключает соединение.

Проверки: `validation.txt` — интерфейс и одиночный режим в редакторе; `online-validation.txt` — реальное подключение к Photon lobby и быстрый вход в сетевую комнату. Двухклиентный вход в пользовательскую комнату и WebGL пока не проверялись.
