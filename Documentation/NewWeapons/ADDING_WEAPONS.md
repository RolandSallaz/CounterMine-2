# Как вручную добавить оружие в CounterMine

Работай в Unity 6000.3.11f1 вне Play Mode. Основные места: `Assets/Resources/Player.prefab` (модель, анимации и характеристики) и `Assets/Resources/ShopCatalog.asset` (магазин). Одного добавления FBX или записи в магазин недостаточно.

## 1. Подготовь модель и ID

1. Импортируй FBX в `Assets/models`, материалы — в свою папку оружия. Используй материалы URP. Для анимаций подвижных частей отключи Optimize Game Objects, чтобы кости оставались доступны.
2. Придумай постоянный уникальный ID латиницей, например `m4a1`. Он должен совпадать в каталоге оружия, магазине и аудиопрофиле. После релиза не переименовывай ID: по нему сохраняются покупки и передаётся оружие по сети.
3. Открой `Assets/Resources/Player.prefab` в Prefab Mode. Найди компонент `WeaponIdleSynchronizer` и массив `Weapons`. Через ссылку `Animator` у `hk416` найди объект `HK416_Weapon`.
4. Дублируй этот объект под тем же родителем и назови `M4A1_Weapon`. Для снайперской винтовки удобнее копировать `L115A3_Weapon`, для пистолета — оружие `ucp`. Оставь старое оружие на месте.
5. Замени модель внутри копии, настрой масштаб и положение. Оставь компоненты `Animator`, `AnimancerComponent` и `WeaponAimRig`. Проверь, что `AnimancerComponent.Animator` указывает на Animator новой копии. Сохрани слой оригинального оружия на всех дочерних объектах.

Не запускай установщики существующего оружия ради добавления своей модели: они заново настраивают свои объекты и могут перезаписать ручную настройку HK416/L115A3.

## 2. Настрой хват, ствол и прицел

На корне оружия нужны дочерние маркеры:

| Маркер | Что настроить |
| --- | --- |
| `RightGrip` | Положение и вращение правой руки на рукоятке. Ориентируйся по маркеру скопированного оружия. |
| `LeftGrip` | Хват левой руки на цевье. |
| `Muzzle` | Конец ствола; синяя ось `+Z` направлена вперёд по линии выстрела. |
| `Sight` + `WeaponSight` | Линия прицеливания. Настрой `Eye Relief` и `Aimed Field Of View`. |

В `WeaponAimRig` назначь новый/скопированный `WeaponHandlingProfile` в `Handling`, а новый прицел — в `Default Sight`. Профиль можно создать через `Create > CounterMine > Weapon Handling`; он управляет скоростью ADS, чувствительностью и движением при прицеливании. Дублируй профиль перед изменением, если его использует другое оружие.

Если есть `WeaponMagazineMotion`, переназначь `Magazine` на магазин новой модели, `Left Grip` на новый маркер и `Source` на общий `WeaponIdleSynchronizer`. Если движения магазина не нужно — убери этот компонент. Проверь все ссылки копии: они не должны оставаться на деталях старого оружия.

Для оптики копируй также `ScopedSightView` и связанные настройки L115A3. Настрой их под положение линзы новой модели; одного уменьшения FOV недостаточно для маски оптического прицела.

## 3. Добавь запись в WeaponIdleSynchronizer

Увеличь массив `Weapons` на один элемент (удобно дублировать запись похожего оружия). Назначь:

| Поле | Пример / назначение |
| --- | --- |
| `Id` | `m4a1`, точно как в магазине |
| `Animator` | `AnimancerComponent` нового оружия |
| `Aim Rig` | Новый `WeaponAimRig` |
| `Muzzle`, `Left Grip`, `Right Grip` | Новые маркеры |
| `Maximum Muzzle Reach` | Допустимое удаление ствола от игрока; у HK416 1 м, у L115A3 1,6 м |
| `Magazine Size` | Например, 30 |
| `Finite Reserve` | Выключено для обычного оружия с бесконечным запасом |
| `Rounds Per Minute` | Например, 700 |
| `Automatic` | Включено для автоматического огня |
| `Damage` | Базовый урон, например 30 |
| `Recoil Kick`, `Recoil` | Сила отдачи, анимация отдачи, движение камеры и разброс |
| `Bolt Bone Name` | Точное имя подвижной кости затвора; не найденная кость просто не двигается |
| `Bolt Travel`, `Bolt Cycle Seconds` | Ход и длительность движения затвора |
| `Character Idle`, `Weapon Idle` | Обязательные клипы персонажа и оружия |
| `Procedural Equip Seconds` | Например, 0,48 для процедурного доставания |
| `Procedural Reload Seconds` | Например, 2,45 для процедурной перезарядки |

Без `Animator`, `Character Idle` или `Weapon Idle` переключение на оружие отклоняется. При копировании HK416 можно сохранить его клип `Idle` и дочерний `IdleClock`: этот клип служит часами для процедурных действий. Сначала используй подходящий существующий `Character Idle`, затем настрой хват.

Для собственных анимаций назначь пары `Character Equip` / `Weapon Equip`. Для перезарядки добавь в `Actions` элемент с `Id = reload` и парой `Character Clip` / `Weapon Clip`; при этом `Procedural Reload Seconds` поставь в 0. Иначе приоритет будет у процедурной перезарядки. Клип персонажа должен соответствовать скелету игрока, оружейный — иерархии нового оружия.

Оставь `Default Weapon Id = ak74`. Новый корень оружия сохрани выключенным: `WeaponIdleSynchronizer` сам включает выбранный объект. Сохрани префаб.

## 4. Добавь звуки

Дублируй `Assets/Resources/Audio/Weapons/hk416.asset` в `m4a1.asset`. Настрой `Display Name`, массив выстрелов, громкость, дальность и звуки действий. Назначь профиль в `Audio Profile` новой записи оружия.

Путь `Resources/Audio/Weapons/<id>.asset` важен и для отображаемого имени в HUD/ленте убийств: `GameAudio` ищет профиль по ID. Копирование профиля без переименования файла не подключает его к новому ID.

## 5. Добавь товар в магазин

Открой `Assets/Resources/ShopCatalog.asset`, добавь элемент в `Items`:

| Поле | Пример |
| --- | --- |
| `Id` | `m4a1` |
| `Title` | `M4A1` |
| `Description` | `Универсальный автомат.` |
| `Category` | `Primary` для основного оружия, `Pistol` для пистолета |
| `Price` | 800, целое число от 0 |
| `Detail` | `30 ПАТРОНОВ / АВТОМАТИЧЕСКИЙ` |
| `Icon` | `UI/Shop/m4a1` |
| `Key` | 1 для Primary, 2 для Pistol |
| `Kills Required` | 0 для обычного оружия |

Положи картинку в `Assets/Resources/UI/Shop/m4a1.png`, в импорте выбери `Sprite (2D and UI)`. В `Icon` указывай путь относительно `Resources`, без расширения.

Категория определяет слот. Поле `Key` — подпись в магазине: фактическое переключение основного оружия/пистолета уже закреплено за 1/2 в `NetworkWeaponPresentation`. Покупка сохраняется навсегда, выбор применяется при следующем появлении, включая первое на стартовом экране. Цена 0 сама по себе не выдаёт оружие всем игрокам: его всё ещё нужно выбрать/получить.

`ShopCatalog.Defaults()` в `Assets/scripts/ShopCatalog.cs` — резервный каталог, если asset не найден. Добавь туда аналогичную запись, если нужен такой резерв. Для стандартной игры используется asset.

Категория `Skill` не делает обычное оружие новым киллстриком: навыки `radar`/`milkor` имеют отдельную логику активации, зарядов и клавиш. Новый тип навыка требует кода.

## 6. Добавь переводы

Открой `Assets/Resources/GameTranslations.json`. Добавь по записи для точного текста `Description`, `Detail` и, если нужно, `Title`:

```json
{ "source": "Универсальный автомат.", "ru": "Универсальный автомат.", "en": "An all-purpose assault rifle." }
```

Соблюдай запятые между элементами массива `entries`. Регистр, пробелы и переносы в `source` должны совпадать с каталогом. Для собственного ключа также можно использовать `source: weapon.m4a1.description` и записать этот ключ в Description. Названия моделей вроде M4A1 переводить не нужно.

Язык выбирается через Yandex Games SDK, в редакторе — через `SettingsYG2 > Simulation > Language` (`ru`/`en`). Неизвестные языки используют английский. Отсутствующий ключ показывается как исходный текст, поэтому проверяй обе локали вручную.

## 7. Проверь оружие

1. Запусти игру: сначала должен открыться экран подготовки, до «В бой» персонажа на карте нет.
2. Открой магазин, выбери/купи оружие и нажми «В бой». Проверь модель, имя, значок и боезапас.
3. Проверь 1/2, ADS, автоматический/одиночный огонь, урон, звук, движение затвора и хват обеих рук.
4. Опустоши магазин, перезаряди, прерви перезарядку сменой оружия и смертью. Не должно быть бесплатного пополнения или зависшего магазина.
5. После смерти проверь магазин и повторное появление. Перезапусти игру и проверь сохранение покупки и выбора.
6. Проверь вид от другого клиента и вход второго клиента во время матча: оба должны иметь одинаковые префабы, ID и клипы в своей сборке.
7. Повтори проверку магазина и HUD на `ru` и `en`, затем в WebGL-черновике Яндекс Игр.

`Tools > CounterMine > Validate New Weapons` проверяет существующие HK416/L115A3; произвольное новое оружие эта проверка автоматически не охватывает. Боты используют отдельный `Assets/Resources/Bot.prefab`: если оружие нужно ботам, добавь модель и запись также туда и отдельно настрой выбор оружия ботом.

## Если что-то не работает

| Симптом | Что проверить |
| --- | --- |
| Товар есть, оружие не появляется | Совпадение ID и запись в Weapons на Player.prefab |
| Переключение не срабатывает | Animator и оба Idle-клипа; нужная категория магазина |
| Прицел смотрит в сторону | Вращение модели, Sight, хват и положение корня |
| Руки/магазин двигают старую модель | Ссылки скопированной записи, IK-маркеры и WeaponMagazineMotion |
| Нет имени или звука | Audio Profile и файл Resources/Audio/Weapons/<id>.asset |
| Нет иконки | Sprite-импорт и путь Icon без Assets/Resources и расширения |
| Текст не перевёлся | Точное совпадение source в GameTranslations.json |
